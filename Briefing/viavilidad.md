# Análisis de viabilidad - LifeOS

## Viabilidad técnica

🟢 **Viable**

El proyecto puede desarrollarse utilizando HTML, CSS y JavaScript, junto con Vite para configurar la aplicación. Son tecnologías que ahora mismo se conocen o se están aprendiendo.

La dificultad puede aumentar si se añaden muchas funcionalidades, pero para una primera versión debería ser posible desarrollar un MVP con los conocimientos disponibles.

**Acción:** Ninguna para el momento actual. Se deberá controlar el número de funcionalidades para evitar aumentar demasiado la complejidad.

## Viabilidad temporal

🟡 **Viable con condiciones**

De momento no sabemos de cuanto tiempo disponemos, pero en principio debería ser viable. LifeOS incluye varias funcionalidades diferentes, por lo que intentar desarrollar todo desde el principio podría hacer que no se llegase a terminar.

**Acción:** Empezar por un MVP con las funcionalidades principales y dejar las funciones secundarias para una posible fase posterior.

## Viabilidad económica

🟢 **Viable**

No se prevé la necesidad de realizar una inversión económica para desarrollar la primera versión del proyecto. Las herramientas principales que se utilizarán son gratuitas.

Se utilizarán tecnologías y herramientas como HTML, CSS, JavaScript, Vite, Git y GitHub.

**Acción:** Ninguna mientras se mantenga el proyecto dentro de las herramientas gratuitas previstas.

## Viabilidad operativa

🟢 **Viable**

LifeOS está pensado para resolver una necesidad relacionada con la organización personal. Centralizar tareas, eventos, gastos, hábitos y objetivos puede facilitar que el usuario tenga toda esta información en un mismo lugar.

Será necesario comprobar durante el desarrollo que la aplicación resulta sencilla de utilizar y que las diferentes funciones están bien organizadas.

**Acción:** Probar la aplicación durante el desarrollo y comprobar que las funciones principales son fáciles de utilizar.

## Viabilidad legal

🟡 **Viable con condiciones**

La aplicación puede trabajar con información personal introducida por el usuario, como tareas, eventos, gastos o hábitos. Por este motivo, será necesario tener en cuenta la protección de datos y evitar almacenar o utilizar información que no sea necesaria para el funcionamiento de la aplicación.

**Acción:** Aplicar buenas prácticas básicas de protección de datos y revisar qué información se almacena y cómo se utiliza.

## Conclusión

LifeOS es un proyecto viable para desarrollar durante el curso, especialmente si se comienza con una versión reducida que incluya las funciones principales.

Los principales aspectos que pueden afectar al proyecto son el tiempo disponible y la gestión de los datos personales. Por este motivo, se considera importante empezar por un MVP y ampliar la aplicación únicamente si el tiempo y los recursos disponibles lo permiten.

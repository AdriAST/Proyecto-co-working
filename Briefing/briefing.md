# Briefing - LifeOS

## Contexto

LifeOS es una aplicación web SPA pensada para ayudar a organizar diferentes aspectos de la vida diaria desde un mismo lugar.

La idea surge de que actualmente existen muchas aplicaciones diferentes para gestionar tareas, calendario, gastos, hábitos, etc. Con LifeOS queremos reunir algunas de estas funciones en una única aplicación sencilla.

## Problema detectado

Muchas personas utilizan diferentes aplicaciones para organizar su día a día. Esto hace que la información esté repartida entre varias plataformas y puede resultar más difícil tener una visión general de las tareas, eventos, gastos y objetivos personales.

LifeOS busca solucionar este problema centralizando esta información en una sola aplicación.

## Actores / Stakeholders

* **Usuario final:** utilizará la aplicación para organizar sus tareas, eventos, gastos, hábitos y objetivos.
* **Desarrollador:** se encargará del diseño, desarrollo y mantenimiento de la aplicación.
* **Profesor/evaluador:** comprobará que el proyecto cumple los requisitos planteados durante el curso.

## Usuario objetivo

La aplicación está dirigida principalmente a:

* Estudiantes.
* Trabajadores.
* Personas que quieran mejorar su organización personal.
* Usuarios que prefieran tener varias herramientas de organización reunidas en una sola aplicación.

## Objetivos

* Desarrollar una aplicación web que permita gestionar tareas, eventos, gastos, hábitos y objetivos.
* Permitir al usuario consultar de forma sencilla la información relacionada con su organización personal.
* Centralizar diferentes funciones de organización en una única aplicación.
* Mostrar un resumen de la actividad del usuario mediante un dashboard.
* Guardar la información para que los datos no se pierdan al cerrar la aplicación.

## Alcance

En la primera versión de LifeOS se incluirán las siguientes funcionalidades:

* Creación y gestión de tareas.
* Gestión de eventos.
* Registro y control de gastos.
* Seguimiento de hábitos.
* Creación y seguimiento de objetivos.
* Dashboard con un resumen de la información.
* Persistencia de los datos.

El proyecto se centrará inicialmente en desarrollar un MVP con las funciones principales. Se podrán añadir nuevas funcionalidades más adelante si el tiempo disponible lo permite.

## Funcionalidades principales

### Tareas

El usuario podrá crear, modificar y eliminar tareas, además de indicar si están completadas.

### Eventos

El usuario podrá registrar eventos y consultar los acontecimientos que tenga pendientes.

### Gastos

El usuario podrá registrar sus gastos y consultar la información económica introducida.

### Hábitos

El usuario podrá crear hábitos y realizar un seguimiento de su cumplimiento.

### Objetivos

El usuario podrá establecer objetivos personales y comprobar su progreso.

### Dashboard

La aplicación mostrará un resumen de la información más importante del usuario mediante diferentes estadísticas.

### Persistencia

Los datos introducidos por el usuario deberán mantenerse aunque cierre o vuelva a abrir la aplicación.

## Restricciones

### Técnicas

* JavaScript Vanilla.
* HTML y CSS.
* Vite.
* Aplicación SPA.
* El proyecto se desarrollará principalmente con los conocimientos adquiridos durante el curso.

### Temporales

* El desarrollo está limitado al tiempo disponible durante el curso.
* Se priorizará un MVP antes de intentar desarrollar funcionalidades adicionales.

### Económicas

* Se utilizarán herramientas gratuitas.
* No se contempla inicialmente contratar servicios de pago.

### Organizativas

* El proyecto será desarrollado de forma individual.

### Legales

* Se debe realizar un tratamiento responsable de los datos personales.
* Se deberán aplicar medidas básicas de protección de datos.

### Funcionales

* La aplicación deberá cumplir como mínimo con los requisitos definidos para el reto.
* Las funcionalidades que no sean necesarias para el MVP podrán quedar para una fase posterior.

## Recursos

Para desarrollar el proyecto se utilizarán:

* Ordenador personal.
* Visual Studio Code u otro editor de código.
* HTML, CSS y JavaScript.
* Vite.
* Git y GitHub.
* GitHub Projects para organizar el trabajo.

## Plazo

El proyecto se desarrollará durante el tiempo disponible para el reto dentro del curso.

La prioridad será conseguir una primera versión funcional con las funcionalidades principales antes de añadir características secundarias.

## Criterios de éxito

Consideraremos que el proyecto ha cumplido sus objetivos cuando:

* La aplicación pueda ejecutarse correctamente.
* El usuario pueda gestionar las principales áreas definidas.
* Los datos introducidos se mantengan correctamente.
* El usuario pueda consultar un resumen de su actividad.
* La interfaz sea suficientemente clara para utilizar la aplicación sin necesitar conocimientos técnicos.
* Se cumplan los requisitos mínimos establecidos para el proyecto.
